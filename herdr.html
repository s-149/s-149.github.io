Panduan Lengkap: Herdr + Aider + Ollama

Alur kerja dari awal memanggil Herdr, menjalankan AI lokal secara offline tanpa kuota/API berbayar, hingga daftar lengkap perintah & pintasannya.

Dioptimalkan untuk Windows 11 • Intel Core i3 • RAM 8 GB (Model 1.5B)
Langkah 1 • Buka Wadah

Memanggil Aplikasi Herdr

Buka PowerShell atau Windows Terminal, masuk ke folder proyek kamu, lalu jalankan Herdr.

cd D:\lokasi\proyek-kamu
herdr
Jika muncul jendela Settings saat pertama dibuka, tekan Esc untuk menutupnya, lalu tekan Ctrl+b diikuti c (atau klik new) untuk membuka terminal.
Langkah 2 • Panggil Otak AI

Menjalankan Aider + Ollama (Gratis)

Di dalam terminal Herdr, panggil agen Aider dengan model lokal qwen2.5-coder:1.5b yang ringan di RAM 8GB.

aider --model ollama_chat/qwen2.5-coder:1.5b --no-auto-commits --map-tokens 0
Flag --no-auto-commits mencegah error Git lama, dan --map-tokens 0 membuat proses berpikir AI jauh lebih cepat di Intel i3.
Langkah 3 • Mulai Ngoding

Memberi Tugas & Tinggal Kerja

Masukkan file yang ingin diedit ke ingatan AI (hanya file yang perlu saja agar hemat RAM), lalu ketik perintahmu.

/add index.html
Buatkan form login responsif Bootstrap 5
Ingin menutup tampilan Herdr sementara AI bekerja di latar belakang? Tekan Ctrl+b lalu q (Detach).
💡 Aturan Tombol Prefix Herdr: Tombol induk di dalam Herdr adalah Ctrl + b. Cara pakainya: tekan Ctrl+b bersamaan, lepas kedua tombol, lalu tekan tombol perintah berikutnya. Herdr juga mendukung klik mouse penuh pada tab & panel.

1. Daftar Perintah di Dalam Agen AI (Aider)

Prompt & Slash Commands
Perintah Kegunaan & Penjelasan
/add <nama_file> Menambahkan File ke Ingatan AI Wajib dilakukan sebelum menyuruh AI mengedit file yang sudah ada. Jika berada di subfolder repo Git, tulis path lengkapnya (contoh: /add ZESEEN-LAW-OFFICE/index.html).
/drop <nama_file> Mengeluarkan File dari Ingatan AI Menghapus file dari konteks obrolan (ketik /drop saja untuk menghapus semua file). Sangat penting agar RAM 8GB tetap ringan saat berpindah file.
/ls Melihat File yang Sedang Dimuat Menampilkan daftar file apa saja yang saat ini sedang berada di dalam memori obrolan Aider.
/ask <pertanyaan> Bertanya Tanpa Mengubah Kode Meminta AI menjelaskan isi file atau berdiskusi solusi tanpa menyentuh atau mengedit file proyekmu.
/undo Membatalkan Perubahan Terakhir Mengembalikan isi file ke kondisi sebelum editan terakhir dari AI jika hasilnya tidak sesuai keinginan.
/diff Melihat Perubahan Kode (Diff) Menampilkan baris kode mana saja yang baru saja ditambah atau dihapus oleh AI.
/run <perintah_terminal> Menjalankan Perintah PowerShell Menjalankan perintah terminal (seperti /run dir atau /run php artisan test) langsung dari dalam prompt Aider tanpa perlu keluar.
/clear Membersihkan Riwayat Chat Menghapus riwayat percakapan sebelumnya agar token tidak menumpuk dan respon AI kembali cepat.
/exit Keluar dari Aider Menutup sesi agen Aider dan kembali ke terminal PowerShell biasa di dalam Herdr.

2. Perintah CLI Herdr (Dijalankan di PowerShell)

Terminal CLI
Perintah Kegunaan & Penjelasan
herdr Membuka Herdr / Menyambungkan Ulang (Attach) Membuka antarmuka TUI Herdr dan otomatis menyambung kembali ke sesi latar belakang yang masih aktif.
herdr session list Melihat Daftar Sesi Aktif Menampilkan daftar semua sesi Herdr yang sedang berjalan di latar belakang komputer.
herdr session attach <nama> Masuk ke Sesi Tertentu Menyambungkan terminal ke sesi spesifik berdasarkan namanya.
herdr server reload-config Memuat Ulang Konfigurasi Menerapkan perubahan pengaturan config.toml tanpa mematikan agen AI yang sedang berjalan.
herdr server stop Mematikan Server Latar Belakang Menghentikan server herdr-core sepenuhnya. Semua terminal dan proses AI di dalamnya akan ikut berhenti.
herdr update Update Aplikasi Herdr Mengecek dan memperbarui versi Herdr ke rilis terbaru (membutuhkan koneksi internet).
herdr config reset-keys Reset Pintasan Keyboard Mengembalikan kombinasi tombol shortcut ke pengaturan awal bawaan Herdr.
herdr --default-config Lihat Contoh Konfigurasi Bawaan Mencetak contoh file konfigurasi lengkap untuk referensi kustomisasi.

3. Pintasan Sesi, Pengaturan & Bantuan

Shortcut TUI
Kombinasi Tombol Kegunaan & Penjelasan
Ctrl+b lalu ? Buka Daftar Semua Shortcut Menampilkan seluruh pintasan tombol aktif di layar. Tekan / di dalamnya untuk mencari shortcut.
Ctrl+b lalu q Detach (Keluar Tanpa Mematikan AI) Menutup jendela tampilan Herdr sambil membiarkan Aider & Ollama tetap bekerja di latar belakang.
Ctrl+b lalu s Buka Menu Settings Membuka jendela pengaturan dan daftar integrasi agen AI di Herdr. Tekan Esc untuk menutup.
Ctrl+b lalu o Lompat ke Notifikasi Langsung berpindah ke tab/panel agen AI yang baru saja selesai bekerja atau butuh konfirmasi.
Ctrl+b lalu Shift+r Reload Konfigurasi Memuat ulang pengaturan config.toml langsung dari dalam antarmuka Herdr.

4. Manajemen Workspace (Proyek) & Tab

Shortcut TUI
Kombinasi Tombol Kegunaan & Penjelasan
Ctrl+b lalu Shift+n Buat Workspace Baru Membuat ruang kerja proyek terpisah (misal: memisahkan proyek Laravel dan proyek HTML statis).
Ctrl+b lalu w Pindah Workspace Membuka menu navigasi untuk berpindah antar proyek/workspace.
Ctrl+b lalu Shift+w Ubah Nama Workspace Mengganti label nama workspace yang sedang aktif.
Ctrl+b lalu Shift+d Tutup Workspace Menutup workspace beserta seluruh tab dan proses di dalamnya.
Ctrl+b lalu b Tampilkan / Sembunyikan Sidebar Membuka atau menutup panel samping kiri yang memuat daftar workspace dan indikator status agen AI.
Ctrl+b lalu c Buat Tab Baru Membuka tab terminal baru di dalam workspace aktif.
Ctrl+b lalu n / p Tab Berikutnya / Sebelumnya n (Next) untuk pindah ke tab kanan, p (Previous) untuk pindah ke tab kiri.
Ctrl+b lalu 1 sampai 9 Lompat ke Nomor Tab Langsung berpindah ke tab urutan ke-1 hingga ke-9.
Ctrl+b lalu Shift+t Ubah Nama Tab Memberi nama khusus pada tab (misal: "Aider AI" atau "Server PHP").
Ctrl+b lalu Shift+x Tutup Tab Menutup tab yang sedang aktif beserta semua panel di dalamnya.

5. Membagi Layar (Split Panes) & Scroll

Shortcut TUI
Kombinasi Tombol Kegunaan & Penjelasan
Ctrl+b lalu v Split Layar ke Kanan (Berdampingan) Membagi layar jadi kiri dan kanan. Sangat praktis untuk menaruh Aider di kiri dan terminal biasa di kanan.
Ctrl+b lalu - Split Layar ke Bawah (Atas-Bawah) Membagi layar menjadi panel atas dan panel bawah.
Ctrl+b lalu h/j/k/l Pindah Fokus Antar Panel Memindahkan kursor antar panel split (h=kiri, j=bawah, k=atas, l=kanan). Bisa juga langsung klik dengan mouse.
Ctrl+b lalu z Zoom / Perbesar Panel Aktif Memperbesar satu panel menjadi layar penuh sementara. Tekan lagi untuk mengembalikan ke ukuran normal.
Ctrl+b lalu r Ubah Ukuran Panel (Resize Mode) Gunakan tombol panah atau h/j/k/l untuk mengatur lebar/tinggi panel, lalu tekan Enter atau Esc.
Ctrl+b lalu [ Mode Scroll & Copy (Copy Mode) Membekukan layar sementara agar kamu bisa menggulir (scroll) ke atas melihat kode atau log lama. Tekan Esc atau q untuk keluar.
Ctrl+b lalu x Tutup Panel Aktif Menutup panel terminal yang sedang dipilih dan menghentikan program di dalamnya.

6. Navigator & Pemantau Status Agen AI

Session Navigator
Tombol Kegunaan & Penjelasan
Ctrl+b lalu g Buka Session Navigator Membuka jendela pemantau terpusat untuk melihat status semua agen AI di seluruh workspace sekaligus.
b / w / i / d / a Filter Status Agen (Di dalam Navigator) b = Blocked (butuh persetujuanmu), w = Working (sedang berpikir), i = Idle, d = Done (selesai), a = Tampilkan semua.
/ lalu ketik kata kunci Cari Panel / Agen (Di dalam Navigator) Menyaring daftar panel berdasarkan nama proyek atau tugas, lalu tekan Enter untuk langsung lompat ke sana.
Tidak ada perintah yang cocok dengan kata kunci pencarianmu.
