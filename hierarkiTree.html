Sumber data: Wilayah.id (mengacu pada Kepmendagri No. 300.2.2-2138 Tahun 2025). Data kabupaten/kota dan kecamatan serta desa/kelurahan dimuat saat cabang dibuka; koneksi internet diperlukan. Data RW/RT, nama kampung administratif, dan jumlah penduduk per wilayah tidak tersedia pada sumber ini dan tidak ditampilkan tanpa sumber resmi. Jika API tidak dapat diakses, data cadangan dibaca dari wilayah-indonesia.json di folder yang sama.
